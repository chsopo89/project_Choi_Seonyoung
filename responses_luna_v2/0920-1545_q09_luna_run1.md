## 1. 먼저 확인할 사항

장비 모델, 슬롯/포트 종류, IOS/IOS XE/NX-OS 버전, SFP의 정확한 PID와 속도를 확인합니다. 같은 Cisco 정품이라도 다음 조합에 따라 지원 여부가 달라질 수 있습니다.

- 스위치 모델과 포트 종류: SFP, SFP+, SFP28, QSFP 등
- SFP 속도: 1G/10G/25G 등
- 광 종류: SX/LX/SR/LR, 단일모드/다중모드
- 파장, 도달거리, BiDi 여부
- 장비의 소프트웨어 버전과 지원되는 PID
- 포트가 특정 속도만 지원하거나, 브레이크아웃·스택·모듈형 라인카드 제약이 있는지

확인은 다음 순서가 적절합니다. 단, 세부 명령과 출력 형식은 모델 및 OS에 따라 다를 수 있습니다.

## 2. SFP가 장비에 물리적으로 인식되는지 확인

먼저 SFP를 다시 장착하고, 잠금 레버와 커넥터 오염·손상을 확인합니다. 가능하면 장비 전원을 끄지 않고 재장착한 뒤 CLI에서 확인합니다.

```text
show inventory
```

출력에 해당 포트 또는 트랜시버의 제조사, PID, 일련번호가 표시되는지 봅니다.

다음 명령도 확인합니다.

```text
show interfaces transceiver
```

모델과 소프트웨어가 지원하는 경우 상세 정보는 다음과 같이 확인합니다.

```text
show interfaces transceiver detail
```

판단 기준은 다음과 같습니다.

- PID, serial, vendor 정보가 표시됨  
  → SFP의 EEPROM 또는 ID 정보는 읽힌 상태입니다.
- `Not Present`, 정보 공란, `Unknown` 등으로 표시됨  
  → 장착 불량, SFP 불량, 포트의 I2C/EEPROM 읽기 문제, 비지원 모듈 가능성이 있습니다.
- 포트 링크가 없어도 SFP ID 정보는 표시될 수 있습니다.  
  따라서 링크 다운과 SFP 미인식은 별도로 판단해야 합니다.

정확한 명령어와 출력 항목은 장비 모델 및 OS 버전에 따라 다를 수 있습니다. 일부 플랫폼에서는 트랜시버 관련 명령이 다르거나 지원되지 않으므로 해당 모델의 명령어 확인이 필요합니다.

## 3. 포트 상태 확인

다음으로 포트 자체가 활성화되어 있는지 확인합니다.

```text
show interfaces status
```

개별 포트의 상세 상태는 다음 형식으로 확인합니다.

```text
show interfaces <인터페이스명>
```

확인 항목은 다음과 같습니다.

- `administratively down`인지
- `notconnect`, `down`, `err-disabled`인지
- 속도와 duplex가 예상값인지
- 입력 오류, CRC, loss of signal 등이 증가하는지
- 포트가 지원하지 않는 속도나 매체로 설정되어 있는지
- 인터페이스가 해당 SFP 유형을 허용하는 포트인지

포트가 `shutdown` 상태라면 설정 문제이고, SFP 정보는 정상인데 링크만 `notconnect`라면 광패치, 반대편 장비, 속도·파장·광 타입 불일치를 우선 의심합니다.

`err-disabled`의 원인이나 시스템 메시지는 다음으로 확인할 수 있습니다.

```text
show logging
```

## 4. 트랜시버 정보와 DOM 확인

SFP가 인식된 뒤 다음 명령으로 트랜시버 정보를 확인합니다.

```text
show interfaces transceiver detail
```

확인할 항목은 다음과 같습니다.

- 제조사와 PID
- serial number
- 지원 속도와 매체
- 파장 및 도달거리
- 온도
- 전압
- Tx/Rx 광 출력
- Tx/Rx optical power
- 알람 및 warning threshold

DOM 값이 표시되지 않는다고 해서 반드시 SFP 불량은 아닙니다.

- 해당 SFP가 DOM/DDM을 지원하지 않을 수 있음
- 장비 또는 소프트웨어가 해당 DOM 항목을 지원하지 않을 수 있음
- 포트가 SFP를 완전히 초기화하지 못했을 수 있음
- 비지원 또는 잘못 코딩된 모듈일 수 있음

DOM 값이 표시되지만 온도, 전압, Tx/Rx power가 비정상이라면 SFP 자체, 광 패치, 반대편 포트, 광 손실을 함께 확인합니다. 특히 Rx power가 매우 낮거나 0에 가까우면 반대편 송신, 광케이블, 파장 불일치를 우선 점검합니다.
