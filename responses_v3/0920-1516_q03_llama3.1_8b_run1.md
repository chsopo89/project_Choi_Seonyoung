1.  **로그 이벤트 생성 여부**
    *   로그 이벤트가 생성되는지 확인하려면, 로그 이벤트가 생성된 후에 로그 이벤트를 확인하는 방법으로 접근할 수 있습니다.
        *   로그 이벤트가 생성되지 않으면, 로그 이벤트의 생성을 활성화 한 후 다시 확인합니다.
        *   로그 이벤트가 생성되지 않는다면, 로그 이벤트가 생성되는 로그 레벨을 확인하고 로그 레벨을 높여 로그 이벤트를 생성하도록 합니다.

2.  **로그 이벤트 로컬 저장 또는 메모리 처리 단계까지 도달 여부**
    *   로그 이벤트가 로컬 저장 또는 메모리 처리 단계까지 도달하는지 확인하려면, 로그 이벤트가 로컬에 저장되거나 메모리에 처리되는지 확인합니다.
        *   로그 이벤트가 로컬에 저장되지 않으면, 로그 이벤트의 로컬 저장 설정을 확인하고 로그 이벤트의 로컬 저장을 활성화 한 후 다시 확인합니다.
        *   로그 이벤트가 로컬에 저장되지 않는다면, 로그 이벤트를 로컬에 저장하도록 설정합니다.

3.  **로그 서버로 전송 시도 여부**
    *   로그 이벤트가 외부 로그 서버로 전송되는지 확인하려면, 로그 이벤트가 외부 로그 서버로 전송되는지 확인합니다.
        *   로그 이벤트가 외부 로그 서버로 전송되지 않으면, 로그 이벤트의 로그 서버 전송 설정을 확인하고 로그 이벤트의 로그 서버 전송을 활성화 한 후 다시 확인합니다.
        *   로그 이벤트가 외부 로그 서버로 전송되지 않는다면, 로그 이벤트를 외부 로그 서버로 전송하도록 설정합니다.

4.  **로그 패킷 송신 여부**
    *   로그 이벤트가 실제로 로그 패킷으로 송신되는지 확인하려면, 로그 패킷이 송신되는지 확인합니다.
        *   로그 패킷이 송신되지 않으면, 로그 패킷의 송신 설정을 확인하고 로그 패킷의 송신을 활성화 한 후 다시 확인합니다.
        *   로그 패킷이 송신되지 않는다면, 로그 패킷을 송신하도록 설정합니다.

5.  **로그 서버 수신 여부**
    *   로그 패킷이 외부 로그 서버에 실제로 수신되는지 확인하려면, 로그 패킷이 외부 로그 서버에 수신되는지 확인합니다.
        *   로그 패킷이 외부 로그 서버에 수신되지 않으면, 로그 패킷의 수신 설정을 확인하고 로그 패킷의 수신을 활성화 한 후 다시 확인합니다.
        *   로그 패킷이 외부 로그 서버에 수신되지 않는다면, 로그 패킷을 외부 로그 서버에 수신하도록 설정합니다.

6.  **각 단계의 결과에 따라 문제를 생성·저장·전송·수신 중 어느 구간으로 좁힐 수 있는지**
    *   각 단계에서 로그 이벤트가 생성되지 않거나 로컬 저장 또는 메모리 처리 단계까지 도달하지 않으면, 로그 이벤트의 생성, 로컬 저장 또는 메모리 처리 단계를 확인하고 활성화 한 후 다시 확인합니다.
    *   로그 이벤트가 외부 로그 서버로 전송되지 않거나 로그 패킷이 송신되지 않으면, 로그 이벤트의 로그 서버 전송 설정과 로그 패킷의 송신 설정을 확인하고 활성화 한 후 다시 확인합니다.
    *   로그 패킷이 외부 로그 서버에 수신되지 않으면, 로그 패킷의 수신 설정을 확인하고 활성화 한 후 다시 확인합니다.

**FortiOS 7.6 명령어**

*   **get system log setting**: 로그 이벤트의 생성, 로컬 저장 또는 메모리 처리 단계를 확인할 수 있습니다.
*   **set system log setting**: 로그 이벤트의 생성, 로컬 저장 또는 메모리 처리 단계를 활성화 할 수 있습니다.
*   **get system log server setting**: 로그 이벤트가 외부 로그 서버로 전송되는지 확인할 수 있습니다.
*   **set system log server setting**: 로그 이벤트가 외부 로그 서버로 전송되도록 설정할 수 있습니다.
*   **get system log packet setting**: 로그 패킷이 송신되는지 확인할 수 있습니다.
*   **set system log packet setting**: 로그 패킷이 송신되도록 설정할 수 있습니다.
*   **get system log packet status**: 로그 패킷이 외부 로그 서버에 수신되는지 확인할 수 있습니다.
