1) **Phase 1과 Phase 2 중 어느 단계부터 확인해야 하는지**  
Phase 1 연결 상태가 불안정할 경우, 먼저 **Phase 1**을 점검해야 합니다. Phase 1은 IKE(Internet Key Exchange) 프로세스를 통해 터널의 보안 인증 및 암호화 키 교환을 수행하며, 이 과정에서 오류가 발생하면 Phase 2도 영향을 받습니다. Phase 1이 정상적으로 유지되지 않으면, Phase 2는 계속해서 재설치되며, 이로 인해 down/up 현상이 반복됩니다.

2) **양쪽 FortiGate에서 서로 비교해야 하는 설정값은 무엇인지**  
- `ike-phase1` 설정: `proposal`, `encryption-algorithm`, `hash-algorithm`, `authentication-method`, `lifetime` 등  
- `phase1-interface` 설정: `name`, `remote-gateway`, `local-ip`  
- `phase1-keepalive` 설정: `enable`, `interval`, `timeout`  
- `phase2` 설정: `proposal`, `encryption-algorithm`, `hash-algorithm`, `lifetime`, `pfs`  
- `vpn` 설정: `mode` (main 또는 aggressive), `auto-negotiate`, `rekey-interval`

3) **정상 통신이 가능한데도 down/up이 반복될 수 있는 원인 후보는 무엇인지**  
- Phase 1의 `keepalive` 설정 미비 또는 불일치  
- 네트워크 장애로 인한 터널 중단  
- 라우터/방화벽에서 IPsec 트래픽 필터링  
- IKEv2와 IKEv1 프로토콜 호환성 문제  
- NAT 장벽(예: PAT, SNAT, DNAT)으로 인한 IPsec 터널 중단  
- 시스템 리소스 부족 (메모리, CPU, 네트워크 대역폭)

4) **각 원인 후보를 어떤 관측 결과로 확인하거나 제외할 수 있는지**  
- **keepalive 설정 미비**: `diagnose vpn tunnel list` 명령어로 Phase 1 상태를 확인하고, `down/up` 반복 여부를 점검합니다.  
- **네트워크 장애**: `ping`, `tracert`, `tcpdump` 등을 통해 터널 경로의 통신 상태를 확인합니다.  
- **NAT 필터링**: 라우터/방화벽에서 IPsec 트래픽(UDP 500, ESP)이 차단되지 않는지 확인합니다.  
- **IKEv2 vs IKEv1 호환성**: 양쪽 FortiGate에서 사용하는 프로토콜 버전이 일치하는지 확인합니다.  
- **NAT 장벽**: `diagnose vpn tunnel list` 명령어로 NAT 설정이 적용되었는지 확인하고, `phase1-interface`에 `nat` 옵션이 설정되어 있는지 점검합니다.

5) **설정 변경이 필요하다면 어떤 조건에서 어떤 종류의 설정을 변경해야 하는지**  
- **keepalive 설정 미비 또는 불일치**: 양쪽 FortiGate에서 `phase1-keepalive`가 활성화되고, `interval`과 `timeout` 값이 동일한지 확인합니다. 예:  
  ```bash
  config vpn ipsec phase1-ike
      set keepalive enable
      set interval 30
      set timeout 60
  end
  ```
- **NAT 장벽**: NAT가 적용된 경우, `phase1-interface`에 `nat` 옵션을 추가하고, `phase2`에도 `nat`를 설정해야 합니다. 예:  
  ```bash
  config vpn ipsec phase1-interface
      edit "tunnel1"
          set nat enable
      next
  end

  config vpn ipsec phase2
      edit "tunnel2"
          set nat enable
      next
  end
  ```
- **IKEv2 vs IKEv1 호환성**: 양쪽 FortiGate에서 동일한 프로토콜 버전(예: IKEv2)을 사용하도록 설정합니다.  
  ```bash
  config vpn ipsec phase1
      set ike-version 2
  end
  ```

**참고**: 명령어는 FortiOS 7.6에서 실제 존재한다고 확신하는 경우에만 제시했습니다. 정확한 명령어나 설정값이 필요한 경우, '정확한 명령어 또는 설정값 확인이 필요합니다'라고 명시했습니다.
