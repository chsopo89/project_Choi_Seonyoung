네트워크 장비 전환 시점에 발생할 수 있는 다양한 문제를 점검하고 해결하는 방법에 대한 내용입니다.

**1. 트렁크 인터페이스에서 실제로 허용되거나 멤버로 포함된 VLAN을 확인하는 방법**

*   Cisco IOS XE: `show vlan | include <VLAN_ID>` (예: `show vlan | include 10`)
*   Junos OS: `show vlans` 또는 `show interfaces <interface> detail`

**2. 문제가 발생하는 VLAN의 태깅 및 포트 멤버십 상태를 확인하는 방법**

*   Cisco IOS XE: `show interface <interface> switchport`
*   Junos OS: `show interfaces <interface> detail` 또는 `show vlans <VLAN_ID> detail`

**3. STP 상태를 확인하여 새로 연결한 포트가 루프와 관련 있는지 판단하는 방법**

*   Cisco IOS XE: `show spanning-tree summary` 또는 `show spanning-tree <VLAN_ID>`
*   Junos OS: `show spanning-tree` 또는 `show spanning-tree <VLAN_ID> detail`

**4. MAC 주소 학습 상태를 이용하여 문제 VLAN의 L2 전달 경로를 확인하는 방법**

*   Cisco IOS XE: `show mac address-table`
*   Junos OS: `show mac-table` 또는 `show interfaces <interface> detail`

**5. 링크 up 및 LLDP 인식과 VLAN 트래픽 전달 성공을 서로 다른 상태로 구분해야 하는 이유**

링크가 UP이지만 LLDP 인식이 되지 않거나 VLAN 트래픽 전달이 실패할 수 있으므로, 두 가지 상태를 분리하여 확인해야 합니다.

**6. 명령어**

*   Cisco IOS XE:
    *   `show vlan | include <VLAN_ID>`
    *   `show interface <interface> switchport`
    *   `show spanning-tree summary`
    *   `show mac address-table`
*   Junos OS:
    *   `show vlans`
    *   `show interfaces <interface> detail`
    *   `show spanning-tree`
    *   `show mac-table`

**7. 한쪽 벤더의 명령어나 기능을 다른 벤더에도 동일하게 적용하지 말 것**

각 벤더별로 명령어나 기능이 다를 수 있으므로, 각 장비에 맞는 명령어와 기능을 사용해야 합니다.

**8. 설정을 변경하기 전에 현재 상태를 확인하고 백업해야 할 항목**

현재 VLAN 구성, 포트 멤버십, STP 상태, MAC 주소 학습 상태 등 모든 설정을 확인하고 백업해야 합니다.

**9. 루프 위험을 최소화하면서 기존 Cisco에서 Juniper로 단계적으로 트래픽을 이전하는 순서**

1.  기존 Cisco 스위치에서 VLAN을 분리하여 Juniper 스위치에 연결합니다.
2.  Juniper 스위치에서 VLAN을 구성하고 포트 멤버십을 설정합니다.
3.  STP를 활성화하고 새로 연결한 포트가 루프와 관련 있는지 확인합니다.
4.  MAC 주소 학습 상태를 확인하여 문제 VLAN의 L2 전달 경로를 확인합니다.

**10. 각 단계에서 문제가 발생했을 때 다음 단계로 진행할지 원복할지를 판단할 기준**

*   문제가 발생하면, 이전 단계로 돌아가서 다시 시도하거나, 현재 상태를 백업하고 다음 단계로 진행합니다.

장비 모델이나 세부 OS 버전에 따라 명령어가 달라질 수 있으므로, 정확한 명령어를 확신하지 못하면 추측하지 말고 '정확한 명령어 확인이 필요합니다'라고 답하세요.
