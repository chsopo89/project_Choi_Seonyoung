1.  **로그 이벤트 생성 여부**
    *   로그 이벤트가 생성되는지 확인하려면, 로그 이벤트가 발생하는 장비의 로그 설정을 확인해야 합니다. FortiGate에서 로그 이벤트는 로그 레벨에 따라 다양한 수준의 세부 정보를 포함하는 로그 메시지를 생성할 수 있습니다.
        *   로그 레벨은 시스템 관리자가 로그 이벤트의 중요도에 따라 설정할 수 있습니다. 로그 레벨이 낮게 설정되어 있으면 로그 이벤트가 생성되지 않을 수 있습니다.
            *   로그 레벨을 확인하고 조정하는 명령어: `get system log level`
    *   로그 이벤트가 생성되는지 확인하려면, 로그 이벤트가 발생한 시간대에 해당하는 로그 파일을 확인해야 합니다. FortiGate에서 로그 파일은 로그 레벨에 따라 다양한 수준의 세부 정보를 포함하는 로그 메시지를 저장합니다.
        *   로그 파일을 확인하는 명령어: `show log <log-level>`

2.  **로그 이벤트 로컬 저장 또는 메모리 처리 단계까지 도달 여부**
    *   로그 이벤트가 생성된 후 로컬 저장 또는 메모리 처리 단계까지 도달하는지 확인하려면, 로그 설정을 확인해야 합니다. FortiGate에서 로그 이벤트는 로컬 저장 또는 메모리 처리 단계로 전송될 수 있습니다.
        *   로그 이벤트가 로컬 저장 또는 메모리 처리 단계까지 도달하는지 확인하는 명령어: `get system log setting`
    *   로그 이벤트가 로컬 저장 또는 메모리 처리 단계까지 도달하지 못하는 경우, 로그 이벤트가 생성되지 않은 것으로 판단할 수 있습니다.

3.  **외부 로그 서버로 전송 여부**
    *   로그 이벤트가 외부 로그 서버로 전송되는지 확인하려면, 로그 설정을 확인해야 합니다. FortiGate에서 로그 이벤트는 외부 로그 서버로 전송될 수 있습니다.
        *   로그 이벤트가 외부 로그 서버로 전송되는지 확인하는 명령어: `get system log setting`
    *   로그 이벤트가 외부 로그 서버로 전송되지 않는 경우, 로그 이벤트가 로컬 저장 또는 메모리 처리 단계까지 도달하지 못한 것으로 판단할 수 있습니다.

4.  **FortiGate에서 실제 로그 패킷이 송신 여부**
    *   로그 이벤트가 외부 로그 서버로 전송되는지 확인하려면, 로그 패킷의 송신을 확인해야 합니다. FortiGate에서 로그 패킷은 로그 이벤트를 포함하여 외부 로그 서버로 전송됩니다.
        *   로그 패킷의 송신을 확인하는 명령어: `get system log setting` (로그 패킷의 송신 여부는 로그 설정에 따라 달라질 수 있으므로, 로그 설정을 확인해야 합니다.)

5.  **로그 서버가 해당 패킷을 실제로 수신 여부**
    *   로그 패킷이 외부 로그 서버로 전송되는지 확인하려면, 로그 서버의 로그 파일을 확인해야 합니다. 로그 서버에서 로그 패킷은 로그 이벤트를 포함하여 저장됩니다.
        *   로그 패킷이 로그 서버로 전송되는지 확인하는 명령어: `show log <log-level>` (로그 서버의 로그 파일을 확인해야 하므로, 로그 서버의 로그 파일을 확인해야 합니다.)

6.  **각 단계의 결과에 따라 문제를 생성·저장·전송·수신 중 어느 구간으로 좁힐 수 있는지**
    *   로그 이벤트가 생성되지 않은 경우, 로그 레벨 설정을 확인해야 합니다.
    *   로그 이벤트가 로컬 저장 또는 메모리 처리 단계까지 도달하지 못한 경우, 로그 설정을 확인해야 합니다.
    *   로그 패킷이 외부 로그 서버로 전송되지 않는 경우, 로그 설정을 확인해야 합니다.
    *   로그 패킷이 로그 서버로 전송되지 않는 경우, 로그 서버의 로그 파일을 확인해야 합니다.

위의 내용은 FortiGate에서 로그 이벤트를 생성하고 외부 로그 서버로 전송하는 과정을 설명하였습니다. 각 단계에서 사용할 수 있는 FortiOS 7.6 명령어는 다음과 같습니다.

*   `get system log level` : 로그 레벨을 확인합니다.
*   `show log <log-level>` : 로그 파일을 확인합니다.
*   `get system log setting` : 로그 설정을 확인합니다.

위의 명령어는 실제 존재 여부나 정확한 문법을 확신하지 못하면 명령어를 만들어내지 않았습니다.
