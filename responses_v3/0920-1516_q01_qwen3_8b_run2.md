1) **Phase 1과 Phase 2 중 어느 단계부터 확인해야 하는지**  
Phase 1 연결 상태가 불안정할 경우, 먼저 **Phase 1**을 점검해야 합니다. Phase 1은 IKE(Internet Key Exchange) 프로세스로, 터널의 보안 인증 및 암호화 키 교환을 담당하며, 이 단계에서의 오류는 전체 VPN 연결에 영향을 줍니다. Phase 2는 IPsec SA(Security Association) 생성 단계로, Phase 1이 정상적으로 성공한 후에 실행됩니다. 따라서 Phase 1의 문제를 우선 확인하는 것이 중요합니다.

2) **양쪽 FortiGate에서 서로 비교해야 하는 설정값은 무엇인지**  
- `phase1-id` 또는 `id` 값: 양쪽 장치에서 동일한 값을 사용해야 합니다.  
- `proposal` 및 `encryption-algorithm`, `hash-algorithm`: 암호화 알고리즘과 해시 알고리즘이 일치해야 합니다.  
- `authentication-method`: 패스워드나 디지털 인증서 등 인증 방식이 일치해야 합니다.  
- `ike-version`: IKEv1 또는 IKEv2 중 하나로, 양쪽 장치가 동일한 버전을 사용해야 합니다.  
- `dpd` 설정(Dead Peer Detection): DPD 시간 간격이나 행동이 일치해야 합니다.  
- `lifetime`: Phase 1 SA의 유효 기간이 일치해야 합니다.

3) **정상 통신이 가능한데도 down/up이 반복될 수 있는 원인 후보는 무엇인지**  
- **DPD(Dead Peer Detection)**: 터널이 정상적으로 작동하지만, DPD 인터벌이 짧아 빈번하게 상태 변경이 발생할 수 있습니다.  
- **Phase 1 SA의 유효 기간(lifetime)**: 설정된 시간보다 긴 시간 동안 터널이 활성화되어 있으면, Phase 1 SA가 만료되어 재설정됩니다.  
- **IKEv2에서의 Keepalive 설정**: IKEv2에서는 Keepalive 메시지 없이도 터널이 유지될 수 있지만, 일부 환경에서는 자동으로 연결을 종료할 수 있습니다.  
- **NAT Traversal(NAT-T) 또는 NAT Reflection 설정 불일치**: NAT 환경에서 이 설정이 잘못되면 터널이 끊깁니다.  
- **시스템 리소스 부족**: CPU나 메모리 사용량이 과부하되면 상태 변경이 발생할 수 있습니다.

4) **각 원인 후보를 어떤 관측 결과로 확인하거나 제외할 수 있는지**  
- DPD 문제: `diagnose vpn ike log` 명령어로 DPD 관련 로그를 확인합니다. DPD 인터벌이 짧거나, 자주 "Dead Peer Detected" 메시지가 나타난다면 DPD 설정을 조정해야 합니다.  
- Phase 1 SA 유효 기간: `diagnose vpn tunnel list` 명령어로 현재 터널의 Phase 1 SA 생성 시간과 만료 시간을 확인합니다. 만약 Phase 1 SA가 빈번하게 재생성되고 있다면 lifetime 설정이 짧은 것으로 추정할 수 있습니다.  
- NAT-T 또는 NAT Reflection 불일치: `diagnose vpn ike log`에서 NAT 관련 로그를 확인합니다. 예를 들어, "NAT detected" 메시지가 나타나면 NAT-T 설정이 필요한 경우입니다.  
- 시스템 리소스 부족: `diag sys top` 명령어로 CPU 및 메모리 사용량을 확인합니다. 과부하 상태라면 시스템 리소스를 조정해야 합니다.

5) **설정 변경이 필요하다면 어떤 조건에서 어떤 종류의 설정을 변경해야 하는지**  
- DPD 인터벌을 늘려야 할 경우: 양쪽 FortiGate에서 `set dpd idle-timeout <초>` 또는 `set dpd retry-interval <초>` 값을 조정합니다. 예: `config vpn ipsec phase1-interface edit "Phase1-Interface" set dpd idle-timeout 30 set dpd retry-interval 5 end`.  
- Phase 1 SA 유효 기간을 늘리고자 한다면: `config vpn ipsec phase1-interface edit "Phase1-Interface" set lifetime 28800 end` (28,800초 = 8시간).  
- NAT-T 설정이 필요한 경우: 양쪽 장치에서 `set nat-traversal enable`를 활성화합니다.  
- IKEv2 Keepalive 설정이 필요한 경우: `config vpn ipsec phase1-interface edit "Phase1-Interface" set keepalive 30 end` (30초 간격으로 Keepalive 메시지 전송).  

**참고**: 명령어는 FortiOS 7.6 버전에 따라 정확한 문법을 보장해야 하며, 실제 환경에 따라 조정이 필요할 수 있습니다. 위 명령어는 일반적인 사용 사례에 해당하며, 정확한 명령어 또는 설정값 확인이 필요합니다.
