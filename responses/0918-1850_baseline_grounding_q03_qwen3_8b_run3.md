FortiGate에서 로그가 쌓이지 않고 로그 서버로 전송되지 않는 문제를 해결하기 위해, 다음과 같은 점검 순서와 확인 항목을 중심으로 점검해야 합니다.

1. **로그 설정 확인 (Log Settings)**  
   - **명령어**: `diagnose firewall log setting`  
   - 로그 설정에서 로그 유형(예: system, traffic, application, etc.)이 올바르게 설정되었는지 확인합니다.  
   - 로그 전송 대상 서버(예: FortiAnalyzer, FortiSIEM 등)의 IP 주소와 포트가 올바르게 설정되었는지 확인합니다.  
   - 로그 전송 프로토콜(예: TCP, UDP, SSL)이 올바르게 설정되었는지 확인합니다.

2. **로그 서버 연결 상태 확인**  
   - **명령어**: `diagnose firewall log server`  
   - 로그 서버의 IP 주소, 포트, 프로토콜이 올바르게 설정되었는지 확인합니다.  
   - 서버의 상태가 활성화되었는지 확인합니다.  
   - 서버의 포트가 방화벽에서 허용되었는지 확인합니다. (예: `config firewall policy`, `edit <policy_id>`, `set dst-port <port>`)

3. **로그 전송 상태 확인**  
   - **명령어**: `diagnose firewall log status`  
   - 로그 전송이 활성화되었는지 확인합니다.  
   - 로그 전송 중 오류가 발생했는지 확인합니다. (예: "Connection refused", "Authentication failed" 등)

4. **로그 전송 통신 확인**  
   - **명령어**: `diagnose firewall log test <server_ip> <port>`  
   - 로그 서버와의 통신이 정상인지 확인합니다.  
   - 이 명령어는 로그 전송을 테스트하는 데 사용되며, 실패 시 네트워크 문제나 서버 설정 문제를 나타낼 수 있습니다.

5. **로그 전송 프로토콜 및 인증 설정 확인**  
   - 로그 전송 프로토콜이 SSL/TLS인 경우, 인증서가 올바르게 설정되었는지 확인합니다.  
   - 서버의 인증서가 FortiGate에서 인식되는지 확인합니다.  
   - 인증서의 경로와 파일명이 올바르게 설정되었는지 확인합니다.

6. **로그 전송 정책 및 규칙 확인**  
   - 로그 전송을 위한 정책이 올바르게 구성되었는지 확인합니다.  
   - 로그 전송을 위한 규칙이 정책에 포함되었는지 확인합니다.  
   - 정책의 방향(예: outbound)이 올바르게 설정되었는지 확인합니다.

7. **로그 쌓이기 설정 확인**  
   - **명령어**: `config log memory`  
   - 로그 쌓이기 기능이 활성화되었는지 확인합니다.  
   - 로그 쌓이기 용량 제한이 설정되었는지 확인합니다.  
   - 로그 쌓이기가 활성화되어 있지만, 서버로 전송이 실패할 경우, 로그가 임시 저장소에 남아 있을 수 있습니다.

8. **시스템 로그 및 오류 메시지 확인**  
   - **명령어**: `diagnose debug enable`  
   - `diagnose debug view log`  
   - 시스템 로그 및 오류 메시지를 확인하여 로그 전송 관련 오류를 파악합니다.  
   - `diagnose debug disable`로 디버깅을 종료합니다.

9. **FortiGate의 네트워크 설정 확인**  
   - **명령어**: `config system interface`  
   - 로그 전송을 위한 인터페이스가 올바르게 구성되었는지 확인합니다.  
   - 인터페이스의 IP 주소, 서브넷, 게이트웨이가 올바르게 설정되었는지 확인합니다.  
   - 인터페이스의 상태가 활성화되었는지 확인합니다.

10. **FortiGate의 시스템 상태 및 자원 확인**  
    - **명령어**: `diagnose sys info`  
    - 시스템의 메모리, CPU, 디스크 사용량 등을 확인하여 자원 부족으로 인한 로그 전송 실패를 확인합니다.

위 점검 순서를 따라가며, 각 항목을 확인하고 문제를 해결해야 합니다. 문제가 지속될 경우, FortiGate의 로그 설정 및 네트워크 구성에 대한 자세한 검토가 필요할 수 있습니다.
