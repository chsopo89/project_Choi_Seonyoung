Cisco Catalyst 스위치(IOS XE)에 Cisco 정품 광 SFP 모듈을 연결했으나 인식되지 않는다면, 다음과 같은 순서로 장애를 점검하고 확인해야 합니다.

1.  **SFP 모듈의 연결 상태 확인**
    -   SFP 모듈이 스위치에 올바르게 연결되어 있는지 확인합니다. SFP 모듈의 연결을 확인하고, 스위치의 SFP 슬롯에 모듈이 올바르게 삽입되어 있는지 확인합니다.
2.  **SFP 모듈의 인식 상태 확인**
    -   스위치에서 `show interface transceiver` 명령어를 사용하여 SFP 모듈의 인식 상태를 확인합니다. 이 명령어는 스위치에서 SFP 모듈의 상태, 온도, 전압, 등 다양한 정보를 제공합니다.
    -   `show interface transceiver` 명령어를 사용하여 SFP 모듈의 상태를 확인하고, 모듈이 인식되지 않는다면, 다음 단계로 진행합니다.
3.  **SFP 모듈의 장애 확인**
    -   스위치에서 `show logging` 명령어를 사용하여 SFP 모듈의 장애를 확인합니다. 이 명령어는 스위치에서 발생한 모든 로그를 제공합니다.
    -   `show logging` 명령어를 사용하여 SFP 모듈의 장애를 확인하고, 모듈이 인식되지 않는다면, 다음 단계로 진행합니다.
4.  **SFP 모듈의 교체**
    -   SFP 모듈이 인식되지 않는다면, 모듈을 교체합니다. 교체한 모듈이 인식되는지 확인합니다.
5.  **Cisco 정품 SFP와 서드파티 SFP 사용 시**
    -   Cisco 정품 SFP와 서드파티 SFP를 사용할 때, 기술지원 또는 A/S에서 확인해야 할 사항은 다음과 같습니다.
    -   Cisco 정품 SFP와 서드파티 SFP는 호환성에 따라 다를 수 있습니다. Cisco 정품 SFP를 사용하는 것이 권장됩니다.
    -   서드파티 SFP를 사용할 때, Cisco의 기술지원 또는 A/S에서 확인해야 할 사항은, SFP의 호환성, 장애의 원인, 교체 방법 등입니다.

**명령어**

*   `show interface transceiver` : SFP 모듈의 인식 상태를 확인합니다.
*   `show logging` : SFP 모듈의 장애를 확인합니다.

**장비 모델 및 OS 버전**

*   Cisco Catalyst 스위치(IOS XE)

**참고**

*   Cisco 정품 SFP를 사용하는 것이 권장됩니다.
*   서드파티 SFP를 사용할 때, Cisco의 기술지원 또는 A/S에서 확인해야 할 사항이 있습니다.
