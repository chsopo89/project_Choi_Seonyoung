Cisco Catalyst 스위치(IOS XE)에 Cisco 정품 광 SFP 모듈을 연결했으나 인식되지 않는다면, 다음의 순서로 장애를 점검하고 확인해야 합니다.

1.  **show interface** 명령어를 사용하여 인터페이스 상태를 확인합니다. 이 명령어는 스위치의 모든 인터페이스 상태를 표시하며, SFP 모듈이 연결된 인터페이스도 포함됩니다. 명령어의 예는 다음과 같습니다.

    ```
    switch# show interface
    ```
2.  **show interface transceiver** 명령어를 사용하여 SFP 모듈의 상태를 확인합니다. 이 명령어는 SFP 모듈의 상세한 상태를 표시하며, 모듈의 작동 상태, 전압, 온도 등이 포함됩니다. 명령어의 예는 다음과 같습니다.

    ```
    switch# show interface transceiver
    ```
3.  **show inventory** 명령어를 사용하여 장비의 모든 장비를 목록화하여 확인합니다. 이 명령어는 장비의 모든 장비를 목록화하여 확인하며, SFP 모듈도 포함됩니다. 명령어의 예는 다음과 같습니다.

    ```
    switch# show inventory
    ```
4.  **show module** 명령어를 사용하여 모듈의 상태를 확인합니다. 이 명령어는 장비의 모든 모듈의 상태를 표시하며, 모듈의 작동 상태, 전압, 온도 등이 포함됩니다. 명령어의 예는 다음과 같습니다.

    ```
    switch# show module
    ```
5.  **show log** 명령어를 사용하여 장비의 로그를 확인합니다. 이 명령어는 장비의 로그를 표시하며, 장비의 작동 상태, 오류 등이 포함됩니다. 명령어의 예는 다음과 같습니다.

    ```
    switch# show log
    ```
6.  **debug** 명령어를 사용하여 장비의 디버그 로그를 확인합니다. 이 명령어는 장비의 디버그 로그를 표시하며, 장비의 작동 상태, 오류 등이 포함됩니다. 명령어의 예는 다음과 같습니다.

    ```
    switch# debug
    ```
