네트워크 장비 전환 시에는 여러 가지 고려 사항이 필요합니다. 먼저 현재 상황을 분석해 보겠습니다.

*   두 장비는 IEEE 802.1Q로 트렁크 구간을 설정했으며 VLAN ID도 동일하므로 VLAN 관련 설정은 일치하고 있습니다.
*   링크는 up이고 LLDP로 서로 인식되므로 네트워크 연결 자체는 정상적입니다.
*   일부 VLAN만 통신되지 않고 포트를 올린 뒤부터 간헐적으로 루프성 트래픽이 관측된다.

이러한 현상을 해결하기 위해 다음 순서로 확인 및 점검을 진행할 수 있습니다.

### 1. VLAN Trunking Protocol (VTP) 확인

Cisco Catalyst 스위치는 VTP를 사용하여 VLAN 정보를 동기화합니다. Juniper 스위치는 VTP를 지원하지 않습니다. 따라서 Cisco Catalyst 스위치에서 VTP가 활성화되어 있는지 확인하고, 만약 활성화되어 있다면 비활성화하거나 VTP를 무시하는 설정을 적용해야 합니다.

```bash
# Cisco Catalyst 스위치에서 VTP 상태 확인
show vtp status

# VTP 비활성화
configure terminal
vtp mode transparent
```

### 2. Spanning Tree Protocol (STP) 확인

STP는 루프를 방지하기 위해 네트워크 내의 브리지 연결을 관리합니다. 두 장비 모두 STP를 사용할 수 있지만, Juniper 스위치는 MSTP(Multiple Spanning Tree Protocol)를 지원하지 않습니다. 따라서 Cisco Catalyst 스위치에서 MSTP가 활성화되어 있는지 확인하고, 만약 활성화되어 있다면 PVST+로 전환해야 합니다.

```bash
# Cisco Catalyst 스위치에서 STP 상태 확인
show spanning-tree summary

# PVST+로 전환
configure terminal
spanning-tree mode pvst+
```

### 3. VLAN Filter 확인

VLAN 필터는 특정 VLAN을 허용하거나 차단하는 기능입니다. 두 장비 모두 VLAN 필터를 사용할 수 있지만, 설정이 일치하지 않을 수 있습니다. 따라서 각 장비의 VLAN 필터 설정을 확인하고, 필요에 따라 조정해야 합니다.

```bash
# Cisco Catalyst 스위치에서 VLAN 필터 설정 확인
show vlan filter

# Juniper 스위치에서 VLAN 필터 설정 확인
show vlans
```

### 4. Port Channel 확인

포트 채널은 여러 개의 포트를 하나의 논리적 인터페이스로 묶어주는 기능입니다. 두 장비 모두 포트 채널을 지원하지만, 설정이 일치하지 않을 수 있습니다. 따라서 각 장비의 포트 채널 설정을 확인하고, 필요에 따라 조정해야 합니다.

```bash
# Cisco Catalyst 스위치에서 포트 채널 설정 확인
show port-channel summary

# Juniper 스위치에서 포트 채널 설정 확인
show interfaces
```

### 5. VLAN Tagging 확인

VLAN 태깅은 VLAN ID를 패킷 헤더에 추가하는 기능입니다. 두 장비 모두 VLAN 태깅을 지원하지만, 설정이 일치하지 않을 수 있습니다. 따라서 각 장비의 VLAN 태깅 설정을 확인하고, 필요에 따라 조정해야 합니다.

```bash
# Cisco Catalyst 스위치에서 VLAN 태깅 설정 확인
show vlan tagging

# Juniper 스위치에서 VLAN 태깅 설정 확인
show vlans
```

이러한 순서로 확인 및 점검을 진행하면, 루프성 트래픽과 일부 VLAN 통신 불가 문제를 해결할 수 있을 것입니다.
