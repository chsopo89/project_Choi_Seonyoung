FortiGate에서 로그가 쌓이지 않고 로그 서버로 전송되지 않는 문제를 해결하기 위해, 다음과 같은 점검 순서를 추천합니다. 각 항목은 문제의 원인을 파악하는 데 중요한 요소들입니다.

1. **로그 설정 확인**:  
   - `diagnose log config` 명령어를 사용하여 로그 설정을 확인합니다.  
   - 로그 설정에서 로그 서버의 IP 주소, 포트, 프로토콜(예: TCP, UDP, Syslog) 등이 올바르게 설정되어 있는지 확인합니다.  
   - 로그 서버의 IP 주소가 정확하고, 포트가 열려 있는지 확인합니다.

2. **로그 서버 연결 상태 확인**:  
   - `diagnose log test <IP 주소> <포트>` 명령어를 사용하여 로그 서버와의 연결 상태를 테스트합니다.  
   - 이 명령어는 로그 서버에 패킷을 전송하여 연결 상태를 확인합니다.  
   - 실패 시, 네트워크 장애, 포트 차단, 또는 서버 설정 문제를 의심해야 합니다.

3. **로그 전송 상태 확인**:  
   - `diagnose log view` 명령어를 사용하여 로그 전송 상태를 확인합니다.  
   - 이 명령어는 로그 전송 중 발생한 오류나 상태를 보여줍니다.  
   - 예를 들어, "Connection refused", "No route to host" 등의 오류 메시지가 나타나면 네트워크 문제나 서버 설정 문제를 의심해야 합니다.

4. **로그 수집 정책 확인**:  
   - `config log setting` 명령어를 사용하여 로그 수집 정책을 확인합니다.  
   - 로그 수집이 활성화되어 있고, 필요한 로그 유형(예: system, traffic, application)이 포함되어 있는지 확인합니다.  
   - 로그 수집이 비활성화되어 있다면 로그가 쌓이지 않는 원인일 수 있습니다.

5. **로그 버퍼 상태 확인**:  
   - `diagnose log buffer` 명령어를 사용하여 로그 버퍼 상태를 확인합니다.  
   - 로그 버퍼가 가득 차면 로그가 쌓이지 않을 수 있습니다.  
   - 버퍼가 가득 차면 `diagnose log buffer clear` 명령어를 사용하여 버퍼를 비우고, 로그 전송 상태를 다시 확인해야 합니다.

6. **시스템 로그 확인**:  
   - `diagnose log system` 명령어를 사용하여 시스템 로그를 확인합니다.  
   - 시스템 로그에서 로그 전송 관련 오류나 경고 메시지가 있는지 확인합니다.  
   - 예를 들어, "Log server unreachable" 등의 메시지가 나타나면 서버 연결 문제를 의심해야 합니다.

7. **네트워크 장애 확인**:  
   - 로그 서버와 FortiGate 사이의 네트워크 장애가 있는지 확인합니다.  
   - `ping` 명령어를 사용하여 서버와의 연결 상태를 확인합니다.  
   - `tcpdump` 또는 `tcpdump -i <인터페이스> -nn` 명령어를 사용하여 패킷 전송 상태를 확인할 수 있습니다.

8. **로그 서버 설정 확인**:  
   - 로그 서버에서 FortiGate의 로그를 수신하도록 설정되어 있는지 확인합니다.  
   - 로그 서버의 설정에서 로그 형식(예: RFC3164, RFC5424)이 올바르게 설정되어 있는지 확인합니다.  
   - 로그 서버에서 로그를 수신하지 않거나, 형식이 잘못되면 로그가 전송되지 않을 수 있습니다.

9. **FortiGate의 로그 전송 설정 확인**:  
   - `config log setting` 명령어를 사용하여 로그 전송 설정을 확인합니다.  
   - 로그 전송이 활성화되어 있고, 전송 방식(예: TCP, UDP)이 올바르게 설정되어 있는지 확인합니다.

10. **업데이트 및 패치 확인**:  
    - FortiOS 버전이 최신인지 확인합니다.  
    - 로그 전송 관련 버그가 존재할 수 있으므로, 최신 버전으로 업데이트하는 것이 좋습니다.

위 점검 순서를 따라가며 문제 원인을 파악하고, 필요한 경우 로그 서버 설정, 네트워크 설정, 또는 FortiGate의 로그 전송 설정을 수정해야 합니다.
