Cisco 스위치에 광 SFP 모듈을 연결했으나 인식되지 않는다면, 다음의 확인 과정을 거쳐 문제를 해결해 보겠습니다.

### 1. 스위치 상태 확인

스위치 상태를 확인하기 위해 다음 명령어를 사용할 수 있습니다.

```bash
show interface transceiver
```

이 명령어는 스위치의 트랜시버 상태를 확인할 수 있습니다. 트랜시버 상태가 "not present" 또는 "not recognized" 인 경우, 스위치가 모듈을 인식하지 못하는 것으로 추정됩니다.

### 2. 스위치 설정 확인

스위치 설정을 확인하기 위해 다음 명령어를 사용할 수 있습니다.

```bash
show running-config
```

이 명령어는 스위치의 현재 설정을 확인할 수 있습니다. 설정에서 SFP 모듈을 지원하는 포트가 설정되어 있는지 확인합니다.

### 3. 스위치 재부팅

스위치 재부팅을 통해 문제를 해결해 보겠습니다.

```bash
reload
```

스위치가 재부팅되면, 모듈이 다시 인식되는지 확인합니다.
