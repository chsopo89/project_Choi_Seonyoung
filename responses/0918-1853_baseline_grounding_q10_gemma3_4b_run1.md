## Cisco Catalyst 스위치(IOS XE) - Juniper 스위치(Junos OS) 전환 시 문제 해결 및 안전한 진행 절차

현재 상황은 Cisco Catalyst 스위치(IOS XE)와 Juniper 스위치(Junos OS) 간의 장비 이전 작업 중 발생한 VLAN 간 통신 문제 및 간헐적인 루프성 트래픽으로 보입니다. IEEE 802.1Q 트렁크 설정, 동일한 VLAN ID, LLDP 인식 등 기본적인 연결 상태는 정상으로 확인되었지만, 일부 VLAN만 통신되지 않고 루프성 트래픽이 발생한다는 점은 문제의 핵심입니다.

**1. 문제 진단 및 초기 점검 (300~600자)**

* **로그 분석:** 두 스위치의 시스템 로그(Syslog)를 면밀히 분석하여 오류 메시지, 경고 메시지, 트래픽 관련 로그를 확인합니다. 특히, VLAN 관련 메시지, 루프 감지 메시지, 포트 상태 변화 메시지 등을 집중적으로 살펴봅니다. IOS XE와 Junos OS는 로그 형식이 다르므로, 로그 분석 도구 활용이 필요할 수 있습니다.
* **트래픽 분석:** 스위치에 설치된 패킷 분석 도구(예: Wireshark)를 사용하여 VLAN 간 트래픽을 캡처하고 분석합니다. 캡처된 트래픽을 통해 어떤 VLAN 간 통신이 실패하는지, 어떤 종류의 패킷이 루프를 형성하는지 파악합니다.
* **포트 상태 점검:** 각 포트의 상태(Up/Down, Speed, Duplex)를 확인하고, 설정된 VLAN ID와 일치하는지 확인합니다. 포트 설정 오류는 VLAN 간 통신 문제를 유발할 수 있습니다.
* **VLAN 설정 확인:** 두 스위치의 VLAN 설정(VLAN ID, VLAN 멤버십, VLAN 트렁크 설정)을 비교하여 일치하는지 확인합니다. VLAN 설정의 미묘한 차이는 통신 문제를 일으킬 수 있습니다.
* **LLDP 확인:** LLDP 정보를 통해 두 스위치가 서로의 VLAN 정보를 정확하게 인식하는지 확인합니다. LLDP 정보 불일치는 VLAN 트렁크 설정 오류를 암시할 수 있습니다.

**2. 점검 항목 및 순서 (1200~1800자)**

**단계 1: 기본 설정 확인 및 재설정 (600~800자)**

1. **VLAN 트렁크 설정 재확인:** 두 스위치의 VLAN 트렁크 설정(VLAN ID, VLAN 멤버십, 트렁크 포트 설정)을 다시 한번 확인하고, 동일한 설정으로 재구성합니다.
2. **VLAN 정보 동기화:** Junos OS 스위치에서 `vlan sync` 명령어를 사용하여 VLAN 정보를 동기화합니다. (정확한 명령어 확인이 필요합니다)
3. **포트 설정 재설정:** 문제가 발생하는 포트의 설정(Speed, Duplex, VLAN ID)을 초기값으로 재설정합니다.
4. **스위치 재부팅:** 모든 포트 설정 변경 후, 두 스위치를 재부팅하여 설정 변경 사항을 적용합니다. (주의: 재부팅 시 네트워크 연결이 일시적으로 중단될 수 있습니다.)

**단계 2: 트래픽 흐름 분석 및 문제 격리 (600~1000자)**

1. **VLAN 트래픽 필터링:** Junos OS 스위치에서 `set policies traffic class vlan-id <VLAN ID> permit` 명령어를 사용하여 특정 VLAN의 트래픽을 허용하고, 나머지 VLAN의 트래픽을 차단합니다. (정확한 명령어 확인이 필요합니다)
2. **포트별 트래픽 분석:** VLAN 트래픽을 차단한 후, 각 포트에서 발생하는 트래픽을 분석하여 어떤 포트에서 루프성 트래픽이 발생하는지 확인합니다.
3. **라우팅 문제 확인:** VLAN 간 라우팅 설정이 올바르게 구성되었는지 확인합니다. 라우팅 설정 오류는 VLAN 간 통신 문제를 유발할 수 있습니다.
4. **스위치 간 연결 설정 확인:** 두 스위치 간의 연결 설정(MTU, CRC 등)을 확인하고, 설정 오류가 있는지 확인합니다.
5. **QoS 설정 확인:** QoS 설정이 VLAN 간 트래픽에 영향을 미치는지 확인합니다. QoS 설정 오류는 VLAN 간 통신 문제를 유발할 수 있습니다.

**단계 3: 고급 문제 해결 (600~1200자)**

1. **MAC 주소 학습 문제 확인:** 스위치가 MAC 주소를 제대로 학습하지 못하는 경우, VLAN 간 통신 문제가 발생할 수 있습니다. 스위치의 MAC 주소 학습 설정을 확인하고, 필요한 경우 MAC 주소 학습을 강제합니다.
2. **스위치 내부 네트워크 문제 확인:** 두 스위치 내부 네트워크(예: 스위치 간 연결)에 문제가 있는 경우, VLAN 간 통신 문제가 발생할 수 있습니다. 스위치 간 연결 설정을 확인하고, 필요한 경우 스위치 간 연결을 재설정합니다.
3. **펌웨어 버전 확인:** 두 스위치의 펌웨어 버전이 호환되는지 확인합니다. 펌웨어 버전 불일치는 통신 문제를 유발할 수 있습니다.
4. **Junos OS 스위치 설정 검사:** Junos OS 스위치의 설정(예: STP, BPDU 필터링)을 검사하고, 설정 오류가 있는지 확인합니다.

**3. 전환 기간 안전한 진행 절차 (300~600자)**

* **단계적 전환:** 한 번에 모든 VLAN을 전환하는 대신, 작은 규모의 VLAN부터 시작하여 점진적으로 전환합니다.
* **백업 및 복원:** 전환 전에 두 스위치의 설정을 백업하고, 문제가 발생할 경우 복원할 수 있도록 준비합니다.
* **모니터링 강화:** 전환 기간 동안 네트워크 트래픽을 면밀히 모니터링하고, 이상 징후가 발생하면 즉시 대응합니다.
* **문서화:** 모든 설정 변경 사항을 문서화하고, 문제 발생 시 해결 과정을 기록합니다.

**주의사항:**

* 위에서 제시된 명령어는 Cisco Catalyst 스위치(IOS XE)와 Juniper 스위치(Junos OS)에서 실제로 존재하는지 확인해야 합니다.
* Junos OS 스위치에서 `vlan sync` 명령어와 같은 명령어를 사용할 경우, Junos OS 버전 및 설정에 따라 사용 가능한 명령어가 다를 수 있습니다.
* 문제 해결 과정에서 발생할 수 있는 모든 변경 사항을 기록하고, 변경 사항이 네트워크에 미치는 영향을 신중하게 고려해야 합니다.
