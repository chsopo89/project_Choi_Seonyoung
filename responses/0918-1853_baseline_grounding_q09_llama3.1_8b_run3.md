Cisco Catalyst 스위치(IOS XE)에 Cisco 정품 광 SFP 모듈을 연결했으나 인식되지 않는다면, 다음의 순서로 장애를 점검하고 확인해야 합니다.

1.  **SFP 모듈의 연결 상태 확인**
    -   `show interface transceiver` 명령어를 사용하여 SFP 모듈의 연결 상태를 확인합니다. 이 명령어는 스위치의 모든 인터페이스에 대한 트랜시버 정보를 제공합니다.
2.  **SFP 모듈의 종류 및 버전 확인**
    -   `show interface transceiver detail` 명령어를 사용하여 SFP 모듈의 종류, 버전, 그리고 현재 상태를 확인합니다. 이 명령어는 스위치의 모든 인터페이스에 대한 트랜시버 상세 정보를 제공합니다.
3.  **인터페이스 상태 확인**
    -   `show interface` 명령어를 사용하여 인터페이스의 상태를 확인합니다. 이 명령어는 스위치의 모든 인터페이스에 대한 상태 정보를 제공합니다.
4.  **트랜시버의 온도 확인**
    -   `show environment` 명령어를 사용하여 트랜시버의 온도와 다른 환경 정보를 확인합니다. 이 명령어는 스위치의 환경 정보를 제공합니다.
5.  **트랜시버의 상태 확인**
    -   `show interface transceiver` 명령어를 사용하여 트랜시버의 상태를 확인합니다. 이 명령어는 스위치의 모든 인터페이스에 대한 트랜시버 정보를 제공합니다.

Cisco 정품 SFP와 서드파티 SFP 사용 시 기술지원 또는 A/S에서 확인해야 할 사항은 다음과 같습니다.

*   **서포트드 장비**: Cisco 정품 SFP는 Cisco 장비에서만 지원되며, 서드파티 SFP는 일부 Cisco 장비에서만 지원됩니다. 따라서, 장비 모델과 OS 버전을 확인하여 SFP가 지원되는지 확인해야 합니다.
*   **서포트드 OS**: Cisco 정품 SFP는 Cisco의 특정 OS 버전에서만 지원되며, 서드파티 SFP는 일부 Cisco OS 버전에서만 지원됩니다. 따라서, OS 버전을 확인하여 SFP가 지원되는지 확인해야 합니다.
*   **서포트드 장비 모델**: Cisco 정품 SFP는 특정 장비 모델에서만 지원되며, 서드파티 SFP는 일부 장비 모델에서만 지원됩니다. 따라서, 장비 모델을 확인하여 SFP가 지원되는지 확인해야 합니다.

이러한 사항을 확인한 후, 기술지원 또는 A/S에 문의하여 SFP가 지원되는지 확인해야 합니다.
