## FortiGate 7.6 로그 누수 및 전송 실패 문제 해결 가이드

FortiGate 7.6에서 로그가 쌓이지 않고 로그 서버로 전송되지 않는 문제는 다양한 원인으로 발생할 수 있습니다. 아래는 문제 해결을 위한 점검 순서와 각 단계별 확인 사항입니다.

**1단계: 기본적인 확인 및 재현 시도 (1시간 이내)**

* **로그 서버 상태 확인:** 로그 서버의 CPU, 메모리, 디스크 사용량, 네트워크 연결 상태를 확인합니다. 로그 서버의 로그 수용량 설정이 충분한지 확인합니다.
* **FortiGate 재부팅:** FortiGate 장비를 재부팅하여 일시적인 소프트웨어 문제를 해결합니다.
* **로그 설정 재확인:** FortiGate의 로그 설정 (로그 수집 대상, 로그 서버 주소, 로그 전송 프로토콜 등)이 정확하게 설정되었는지 다시 한번 확인합니다. 특히, IP 주소, 포트, 인증 정보 등이 올바른지 확인합니다.
* **로그 전송 프로토콜 확인:** 로그 전송 프로토콜 (HTTP, HTTPS, FTPS 등) 설정이 올바르게 되어 있는지 확인합니다.
* **로그 서버 접근 가능성 확인:** FortiGate에서 로그 서버로의 ping 테스트를 통해 네트워크 연결 상태를 확인합니다.
* **로그 서버 로그 확인:** 로그 서버의 로그를 확인하여 FortiGate에서 전송된 로그 데이터가 있는지 확인합니다. 로그 서버 로그에 FortiGate에서 전송된 데이터가 기록되지 않는다면, FortiGate의 로그 전송 설정에 문제가 있을 가능성이 높습니다.

**2단계: FortiGate 로그 설정 및 기능 점검 (2-4시간 이내)**

* **로그 수집 정책 확인:** FortiGate의 로그 수집 정책이 너무 제한적으로 설정되어 있는지 확인합니다. 예를 들어, 특정 프로토콜 (HTTP, HTTPS 등)의 로그만 수집하도록 설정되어 있다면, 해당 프로토콜의 트래픽이 많을 경우 로그가 누수될 수 있습니다.
* **로그 저장 공간 확인:** FortiGate의 로그 저장 공간이 부족한 경우 로그가 제대로 저장되지 않거나 전송되지 않을 수 있습니다. 로그 저장 공간을 확보하고, 저장 공간이 부족할 경우 로그 저장 설정을 변경합니다.
* **로그 전송 설정 확인:** FortiGate의 로그 전송 설정 (전송 주기, 전송 대상, 인증 방식 등)이 올바르게 설정되었는지 확인합니다.
* **로그 전송 프로토콜 설정 확인:** 로그 전송 프로토콜 설정 (HTTP, HTTPS, FTPS 등)이 올바르게 설정되었는지 확인합니다. 특히, 인증 설정 (사용자 이름, 비밀번호, SSL 인증서 등)이 올바른지 확인합니다.
* **로그 전송 오류 확인:** FortiGate의 시스템 로그 또는 이벤트 로그에서 로그 전송 관련 오류 메시지가 있는지 확인합니다. 오류 메시지를 통해 문제의 원인을 파악할 수 있습니다.
* **로그 전송 설정 테스트:** FortiGate의 로그 전송 설정을 테스트하여 로그가 정상적으로 전송되는지 확인합니다. 테스트를 위해 임시로 로그 서버 주소를 변경하거나, 로그 전송 프로토콜을 변경해 볼 수 있습니다.
* **FortiGate 로그 설정 재시작:** FortiGate의 로그 설정을 초기화하고 다시 설정해 봅니다.

**3단계: FortiGate OS 및 하드웨어 점검 (4-8시간 이내)**

* **FortiGate OS 버전 확인:** FortiGate의 OS 버전이 최신 버전인지 확인합니다. 최신 버전의 OS에는 버그 수정 및 성능 개선 사항이 포함되어 있을 수 있습니다.
* **FortiGate OS 업데이트:** FortiGate의 OS를 최신 버전으로 업데이트합니다.
* **하드웨어 상태 확인:** FortiGate의 CPU, 메모리, 디스크 상태를 확인합니다. 하드웨어 문제로 인해 로그 전송이 지연되거나 실패할 수 있습니다.
* **FortiGate 시스템 로그 확인:** FortiGate의 시스템 로그에서 하드웨어 관련 오류 메시지가 있는지 확인합니다.
* **FortiGate 이벤트 로그 확인:** FortiGate의 이벤트 로그에서 하드웨어 관련 이벤트가 있는지 확인합니다.
* **FortiGate 재부팅:** FortiGate 장비를 재부팅하여 하드웨어 문제를 해결합니다.

**4단계: 고급 문제 해결 (8시간 이후)**

* **FortiGate 펌웨어 업데이트:** FortiOS 7.6 펌웨어의 버그가 로그 전송 문제와 관련될 수 있습니다. 최신 펌웨어로 업데이트하여 문제를 해결합니다.
* **FortiGate 설정 백업 및 복원:** FortiGate의 설정을 백업하고, 복원하여 설정 오류로 인한 문제를 해결합니다.
* **FortiGate 제조사 지원 문의:** 위의 모든 단계를 수행했음에도 문제가 해결되지 않으면, Fortinet 기술 지원팀에 문의하여 도움을 받습니다.

**명령어 예시 (FortiOS 7.6)**

* **로그 설정 확인:**
  `config log syslog`
* **로그 전송 설정 확인:**
  `config log syslog http`
* **로그 저장 공간 확인:**
  `show log storage`
* **시스템 로그 확인:**
  `show log system`
* **이벤트 로그 확인:**
  `show log events`

**주의사항:**

* 위 점검 순서는 일반적인 경우에 해당하며, 실제 문제 해결 과정은 상황에 따라 달라질 수 있습니다.
* FortiGate 7.6은 더 이상 지원되지 않는 버전이므로, 최신 버전으로 업그레이드를 고려해야 합니다.
* 로그 서버 설정 및 FortiGate 설정 변경 시에는 반드시 백업을 수행하고, 변경 사항을 테스트하여 문제가 발생하지 않는지 확인해야 합니다.
* FortiGate의 로그 설정 및 기능은 복잡하므로, 충분한 지식과 경험이 필요합니다.
