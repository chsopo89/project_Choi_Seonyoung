Cisco 스위치에 광 SFP 모듈을 연결했으나 인식되지 않는다면, 먼저 스위치의 상태를 확인해 보는 것이 좋습니다. Cisco 스위치에서 SFP 모듈의 상태를 확인하는 명령어는 다음과 같습니다.

*   `show interface transceiver` 명령어를 사용하여 SFP 모듈의 상태를 확인할 수 있습니다. 이 명령어는 스위치의 모든 인터페이스에 대한 정보를 제공하며, SFP 모듈의 상태, 온도, 전압, 등과 같은 정보를 제공합니다.

    예를 들어, `show interface transceiver` 명령어를 실행한 결과가 다음과 같을 수 있습니다.

    ```
    Switch# show interface transceiver

    Port  Name  Status  Admin  Oper  SFP Type  SFP  SFP  SFP  SFP  SFP  SFP
    1     Eth1/1  connected  up  up  SFP-GE-T  1.2  1.2  1.2  1.2  1.2  1.2
    2     Eth1/2  connected  up  up  SFP-GE-T  1.2  1.2  1.2  1.2  1.2  1.2
    ```

    이 명령어의 결과에서, `Status` 열에서 `connected`가 표시된 경우, SFP 모듈이 스위치에 연결되어 있음을 의미합니다. `Admin` 열에서 `up`이 표시된 경우, SFP 모듈이 활성화되어 있음을 의미합니다. `Oper` 열에서 `up`이 표시된 경우, SFP 모듈이 작동중임을 의미합니다.

    만약 `connected`가 표시되지 않는다면, SFP 모듈이 스위치에 연결되지 않은 것임을 의미합니다. 이 경우, SFP 모듈을 다시 연결하거나, 스위치의 포트를 다시 초기화하는 것이 좋습니다.

    만약 `Admin` 열에서 `up`이 표시되지 않는다면, SFP 모듈이 활성화되지 않은 것임을 의미합니다. 이 경우, `no shutdown` 명령어를 사용하여 SFP 모듈을 활성화할 수 있습니다.
